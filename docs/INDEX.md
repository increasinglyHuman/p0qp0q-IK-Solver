This documentation covers the p0qp0q-IK-Solver project - an enhanced Inverse Kinematics solver for Three.js featuring automatic axis detection, biomechanical constraints, and universal platform support.

## 🎓 Learning Path

### Path 1: Quick Start (30 minutes)
1. Read [README.md](../README.md)
2. Skim [GETTING_STARTED.md](../GETTING_STARTED.md)
3. Review [CONSTRAINT_FORMATS.md](CONSTRAINT_FORMATS.md) examples
4. Run demos in `/examples/`

### Path 2: Deep Understanding (3 hours)
1. Read [GETTING_STARTED.md](../GETTING_STARTED.md) thoroughly
2. Study [MASTER_STRATEGY.md](MASTER_STRATEGY.md)
3. Understand [INTEGRATION_STRATEGY.md](INTEGRATION_STRATEGY.md)
4. Review [SESSION_2025-10-07_BREAKTHROUGH.md](SESSION_2025-10-07_BREAKTHROUGH.md)
5. Explore source code in `/p0qp0q-IK-Solver.js`

### Path 3: Contributor Onboarding (Full day)
1. Complete Path 2
2. Read [CONSTRAINT_FORMATS.md](CONSTRAINT_FORMATS.md) in detail
3. Study [GLTF_BONE_EXTENSION_PROPOSAL.md](GLTF_BONE_EXTENSION_PROPOSAL.md)
4. Review research in `/research/` folder
5. Read [NEXT_STEPS.md](../NEXT_STEPS.md) for current priorities
6. Set up local development environment
7. Run all examples and tests
