🎉 Phase 1-4 Complete! The core universal IK system is functional and deployed. We're at 40% progress toward v1.0!

What Makes This Special

p0qp0q-IK-Solver (pronounced "pock-pock") is not just another IK solver. It's the world's first truly universal IK solver that works with ANY rig, ANY bone orientation, and ANY scale - with ZERO manual configuration.

🔬 Industry-First Innovations

  • Automatic Axis Detection - No other tool (Maya, Blender, Unity, Unreal) has this!
  • Swing-Twist Constraints - Biomechanically accurate, no ±180° wraparound
  • Universal Platform Support - Works with Meshy, Mixamo, Character Creator, TripoAI, custom rigs
  • Scale-Aware Precision - Handles 0.01 to 100+ scale models seamlessly
  • Octahedral Bone Visualization - Professional Maya/Blender-style bone display

Key Features

🎯 Zero Configuration

Load ANY rig and IK just works. No T-pose calibration, no manual axis setup, no platform-specific tweaks.

🦴 Biomechanical Accuracy

Medical-grade ROM data from AAOS guidelines. Constraints based on real human anatomy.

🌐 Universal Support

Works with X, Y, or Z-axis bones. Detects platform automatically. Fuzzy matching for unknown rigs.

⚡ High Performance

Runs at 60fps with multiple IK chains. Optimized CCD algorithm with adaptive precision.

Quick Example

Try it yourself! Visit the live demo to see the solver in action. 
import { P0qP0qIKSolver } from 'p0qp0q-ik-solver';
import { AutoConstraintBuilder } from '@p0qp0q/animation-utils';

// ONE LINE - Build complete IK configuration!
const builder = new AutoConstraintBuilder();
const ikConfig = builder.buildIKConfig(skinnedMesh);

// Create solver and animate
const solver = new P0qP0qIKSolver(skinnedMesh, ikConfig);

function animate() {
    requestAnimationFrame(animate);
    solver.update();  // That's it!
    renderer.render(scene, camera);
}
