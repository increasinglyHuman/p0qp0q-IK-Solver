# Skeleton Types - Complete List for Model Creation

## Bio-Med Logic Skeleton Types Defined

### BIPEDS (Two-legged, upright)
1. **humanoid** - Human and humanoid robots
2. **avian** - Birds, raptors, phoenix, griffin front half

### QUADRUPEDS (Four-legged)
3. **digitigradeQuadruped** - Cats, dogs, wolves, foxes, big cats
4. **unguligradeQuadruped** - Horses, deer, antelope, giraffe, unicorn
5. **plantigradeQuadruped** - Bears, raccoons, badgers

### HEXAPODS (Six-legged)
6. **hexapod** - Insects, beetles, ants, mechanical walkers

### OCTOPODS (Eight-legged)
7. **arachnid** - Spiders, scorpions, mechanical octopods

### SERPENTINE (Snake-like, legless)
8. **serpentine** - Snakes, eels, worms, tentacles, naga

### AQUATIC (Swimming creatures)
9. **aquatic** - Fish, eels, sharks, dolphins, whales, mermaids

### CHIMERIC (Mixed anatomy - mythological)
10. **griffin** - Eagle front (avian) + Lion rear (digitigrade)
11. **centaur** - Human upper + Horse lower (unguligrade)
12. **manticore** - Lion body + Bat wings + Scorpion tail
13. **sphinx** - Lion body + Eagle wings + Human head

## Specialized Components

### Tail Types (can be added to any creature)
- **shortRigid** - Dog, cat relaxed, deer (3-5 segments)
- **longFlexible** - Cat active, monkey, dragon (10-30 segments)
- **prehensile** - Monkey, seahorse, chameleon (15-40 segments, weight-bearing)
- **multipleTails** - Kitsune (9 tails), nekomata (2 tails)
- **aquaticTail** - Mermaid, sea serpent (20-50 segments)
- **scorpionTail** - Scorpion, manticore (5-7 segments, curls over back)

### Wing Types (can be added to avian/chimeric)
- **feathered** - Bird, angel, pegasus, griffin (modified arm)
- **membrane** - Bat, dragon, pteranodon, demon (elongated fingers)
- **insectoid** - Dragonfly, bee, beetle, fairy (4 wings, chitinous)

## Notes for Modelers

- **Quadruped confusion**: The visible "knees" on dogs/cats are actually wrists (front) and ankles (rear)!
- **Bird myth-buster**: The backward-bending joint is the ANKLE, not the knee. The knee is hidden and bends forward.
- **Horse anatomy**: Stifle = knee, hock = ankle, fetlock = knuckle, pastern = finger bone, hoof = fingertip
- **Chimeric creatures**: Combine biomechanics from multiple types (e.g., griffin = avian front + digitigrade rear)
- **Tails**: Can be added to ANY creature type as separate appendage
- **Wings**: Feathered for birds/angels, membrane for bats/dragons, insectoid for insects/fairies
